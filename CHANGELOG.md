Исходная версия сайта — коммит `092d9d8`.

## Доработки (четвёртый заход)

**Анимации — при каждом появлении на экране**
- Всё, что появляется при прокрутке, проигрывается заново каждый раз, когда блок возвращается на экран: подъём блоков, слова заголовков, мазки под словами, фургон и трекер доставки, волна в подвале. Цифры обнуляются, пока их не видно, и снова набегают.
- Если прокручивать вверх, блоки опускаются на место сверху, а не всплывают снизу.
- При возвращении на первый экран логотип собирается заново.

**Шапка на компьютере**
- Больше не прячется при прокрутке — меню всегда под рукой.
- Панель из прозрачного «жидкого стекла»: фон под ней размыт, по краям светлые блики; над фото — тёмное стекло, над светлыми разделами — светлое, в ночной теме — тёмное.
- При наведении на пункт меню под ним появляется стеклянная «капля», которая перетекает за курсором.

**Шапка на телефоне и планшете**
- Панели и бургер-меню больше нет. Логотип висит в левом верхнем углу поверх страницы и раз в 4 секунды блестит, справа — переключатель день/ночь в стеклянном кружке.
- Навигация — нижняя панель вкладок (теперь тоже из «жидкого стекла» и на планшетах). Кнопка «Установить приложение» перенесена в подвал сайта.
- Нажатие на логотип в шапке — он делает оборот и возвращает на первый экран (на компьютере тоже).

Откатить четвёртый заход целиком: `git revert 04c0afb` (или кнопка **Revert** на странице его PR).

## Доработки (третий заход)

**Заставка: логотип собирается по законам физики**
- Салфетка с приборами и надпись «Будь здоров» теперь самостоятельные детали, а не отрезанные куски: у каждой своя красная подложка и жёлтая обводка, построенные так же, как в оригинальном логотипе (`img/svg/logo-icon.svg`, `img/svg/logo-word.svg`).
- Салфетка вылетает из-под нижнего края примерно на 2/3 ширины экрана и летит по дуге вверх-влево, вращаясь. Надпись въезжает справа, притормаживая, и догоняет её.
- Удар как в жизни: тяжёлая надпись при касании замедляется, лёгкая салфетка получает толчок, и дальше обе детали вместе едут влево по инерции, пока трение их не остановит. В момент касания — вспышка и искорки, детали «вщёлкиваются» в цельный логотип.
- Траектория считается под реальный размер экрана, на телефоне смещение меньше, чтобы логотип не уезжал за край. Клик по логотипу — собрать его заново.

**Сайт всегда открывается с первого экрана**
- Раньше клик по пункту меню дописывал в адрес `#delivery` и т. п., а браузер при обновлении возвращал страницу туда же — заставку было не видно. Теперь меню прокручивает плавно и адрес не меняет, а при загрузке страница начинается сверху.
- Ярлыки установленного приложения («Услуги», «Контакты»…) и Telegram Mini App работают как раньше.

**Просмотр фото**
- Фото в полноэкранном просмотре показывается целиком и по центру. Раньше высокие снимки выводились в натуральную величину и обрезались.

Откатить третий заход целиком: `git revert 50ca8e5` (или кнопка **Revert** на странице его PR).

## Доработки (второй заход)

**Заставка первого экрана**
- Сборка логотипа из двух частей (в третьем заходе переделана — см. выше). Заставка ждёт загрузки фото (не дольше 1 секунды), «включается свет», шапка и нижняя панель вкладок появляются после сборки. Раз в 7 секунд по логотипу пробегает блик.
- Над лотками с едой медленно поднимается лёгкий пар.

**Подчёркивание слов в заголовках**
- Вместо полупрозрачной жёлтой плашки (в тёмной теме она становилась буро-красной под красным текстом) — сочный жёлтый мазок «от руки» под словом. Прорисовывается слева направо, когда заголовок появляется.
- Метки разделов («О нас», «Услуги»…) — светлая «пилюля» с цветной иконкой вместо красного текста на розовом.

**Доставка**
- На фото фургон едет влево, а раньше он въезжал слева направо — задом наперёд. Теперь кадр открывается справа налево, фургон въезжает, тормозит с лёгким «клевком» и останавливается.
- Вместо пунктирной полоски — карточка «доставка в пути», как в приложениях: фирменный фургончик едет от «Кухни» к «Вашему столу», затем «Доставлено вовремя» с галочкой. Анимация играет, только пока карточка на экране.

**Мелкие «фишки»**
- Заголовки разделов появляются по словам.
- Бегущая строка ускоряется при прокрутке и меняет направление вслед за ней.
- Кнопки слегка тянутся за курсором (на компьютере), при нажатии — «волна» от точки касания.
- Фото в галерее при прокрутке чуть смещаются внутри плиток — появляется глубина.
- С настройкой «уменьшить движение» и без JavaScript всё показывается сразу в итоговом виде.

**Как выключить отдельную фишку**, не откатывая остальное — удалить один блок (их легко найти по комментарию):

| Что убрать | Где | Что удалить |
|---|---|---|
| Пар над едой | `index.html` | строку `<div class="hero-steam" …>` |
| Параллакс фото в галерее | `assets/css/main.css` | строку `.js .g-item img { scale: …` |
| Слова в заголовках по очереди | `assets/js/main.js` | блок «Заголовки разделов: слова поднимаются по одному» |
| Скорость бегущей строки | `assets/js/main.js` | блок «Бегущая строка ускоряется…» |
| Кнопки за курсором / «волна» | `assets/js/main.js` | блоки «Магнитные кнопки» / «Волна от точки нажатия» |

Откатить второй заход: сначала четвёртый и третий (`git revert 04c0afb`, `git revert 50ca8e5`), затем `git revert f582e7d`.

## Что нового

**Внешний вид и анимации**
- Плавающая «стеклянная» шапка: уменьшается при прокрутке, прячется при прокрутке вниз, подсвечивает текущий раздел.
- Первый экран: медленный наезд камеры на фото и параллакс, логотип «выпрыгивает», заголовок появляется по словам, фирменные иконки (яблоко, вишня, груша…) парят и следуют за курсором, волна внизу «рисуется».
- Бегущая строка с услугами, вращающийся бейдж «28 лет» (число лет считается автоматически).
- Карточки услуг с 3D-наклоном и подсветкой за курсором, счётчики-цифры, карточка рекорда Гиннесса.
- Галерея-мозаика и просмотр фото: листание свайпом и стрелками, закрытие свайпом вниз.
- Отзывы — карусель со свайпом и автопрокруткой.
- Статус «Открыто сейчас / Закрыто» по московскому времени, кнопки «Маршрут» и «Скопировать адрес».
- Переключатель светлой/тёмной темы (запоминает выбор).
- Уважает системную настройку «уменьшить движение»; без JavaScript весь контент тоже виден.

**Телефон / мини-приложение**
- Нижняя панель вкладок, как в приложении: Главная · Услуги · **Позвонить** · Кухня · Контакты.
- Меню-«шторка» снизу, услуги листаются свайпом.
- Сайт можно установить на главный экран (Android — кнопка «Установить приложение» в меню, iPhone — подсказка там же).
- **Telegram Mini App**: если указать `https://eda.bz` как адрес мини-приложения в @BotFather, сайт откроется внутри Telegram, возьмёт его тему, кнопку «Назад» и вибро-отклик, а ссылки на t.me будут открываться прямо в Telegram.

**Скорость и SEO**
- Фото в формате WebP, на телефон грузится уменьшенная версия главного фото (64 КБ вместо 780 КБ).
- Стили и скрипты вынесены в отдельные файлы `assets/` (браузер их кэширует).
- Favicon, картинка-превью для соцсетей и мессенджеров, разметка schema.org для Яндекса и Google.

## Как откатить

Пока ветка не влита в `main`, на живом сайте ничего не меняется.

**После слияния через Pull Request** самый простой путь — кнопка **Revert** на странице PR в GitHub: она создаст PR, который возвращает всё как было.

**Через git:**

```bash
# Убрать только четвёртый заход (анимации при каждом появлении, новые шапки)
git revert 04c0afb

# Убрать третий и четвёртый заходы (физика заставки, открытие с первого экрана, просмотр фото)
git revert --no-edit 04c0afb
git revert --no-edit 50ca8e5

# Убрать заходы со второго по четвёртый (заставка, мазок, трекер…)
git revert --no-edit 04c0afb
git revert --no-edit 50ca8e5
git revert --no-edit f582e7d

# Убрать режим мини-приложения (нижнюю панель вкладок).
# С четвёртого захода это единственная навигация на телефоне, поэтому сначала
# откатываем четвёртый заход — вернётся меню-бургер. Затем Git спросит про
# файлы app.css/app.js — подтверждаем их удаление:
git revert --no-edit 04c0afb
git revert 33305fc
git rm assets/css/app.css assets/js/app.js
git revert --continue

# Вернуть сайт полностью к исходному виду
git revert --no-edit 04c0afb
git revert --no-edit 50ca8e5
git revert --no-edit f582e7d
git revert --no-edit 092d9d8..0e2a7b2
```

Все варианты проверены: полный откат даёт файлы, идентичные исходным; без мини-приложения сайт работает без ошибок.
Если PR влит с опцией «Squash and merge», хэши выше пропадут — тогда откатывается один общий коммит: `git revert <хэш squash-коммита>`.

Service Worker намеренно не используется — у посетителей ничего не кэшируется «намертво», поэтому откат вступает в силу сразу.

## Структура

```
index.html                 разметка
assets/css/main.css        основные стили
assets/css/app.css         режим мини-приложения (телефон)
assets/js/main.js          интерактив
assets/js/app.js           панель вкладок, установка, Telegram
manifest.webmanifest       манифест приложения
img/webp/                  оптимизированные фото
img/app/                   иконки, favicon, превью для соцсетей
```

Исходные JPG-файлы и TTF-шрифты оставлены на месте. Новые фото лучше добавлять в `img/webp/` в формате WebP шириной до 1200 px.
